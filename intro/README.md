# SDHT intro: "A file becomes a room"

A 60 second original cinematic for a 5.1.2 rig. Picture and sound are generated by code from one score (`score.py`).
Sounds are positioned offline with Spatial-Lab's VBAP engine (`vbap.py`, Apache-2.0) and pre-rendered to channels.
It is not Dolby Atmos and no objects are rendered at playback. The voice-over is synthetic (Kokoro-82M).

Not yet watched in motion, listened to or played on the rig. More, with stills and what was measured: [docs/intro.md](../docs/intro.md).

## Build and play

Needs ffmpeg with libx265 and libx264, Python 3 with NumPy, SciPy, OpenCV, Pillow, `kokoro-onnx` and `soundfile`, and the Inter font (the code expects the path of Ubuntu's `fonts-inter`).

```bash
cd intro
pip install kokoro-onnx soundfile    # in a virtual environment on Ubuntu
./get-voice-model.sh                 # once: about 355 MB, checked against voice-model.sha256
./build.sh                           # film (HDR10 and SDR) and the rig test file; ./build.sh bm_george for another voice

mpv-object-audio sdht-intro-rigtest.mkv    # test file first
mpv-object-audio sdht-intro.mkv
```

Start with the volume knob below the usual setting for the first run.

| File | What it does |
|---|---|
| `score.py` | positions, times, captions, labels |
| `voice.py` | the spoken lines, from the captions |
| `audio.py` | sounds, panning, loudness |
| `video.py` | picture (`--stills 3,12,24` for single frames) |
| `testfile.py` | the 26 s rig test |

Channel order in the files: FL FR FC LFE BL(left height) BR(right height) SL SR.
